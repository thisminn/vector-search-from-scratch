# Codex Operating Rules

- Inspect repository state before modifying files.
- Do not change approved technologies without user permission.
- Do not add dependencies without user approval.
- Do not add secrets, and never commit `.env` files.
- Avoid unrelated changes.
- Keep learning-critical algorithms transparent and directly understandable.
- Do not prematurely implement future learning tasks.
- Do not over-abstract core educational code.
- Require tests for implementation tasks.
- Keep documentation aligned with verified code and repository state.
- Do not fabricate performance results or claim unverified work as complete.
- Do not run `git commit` or `git push`.
- After each task, report all modified files and commands executed.
